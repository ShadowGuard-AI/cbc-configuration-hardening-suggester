First Stretch of the Bench: What the Tool Checks

cbc-configuration-hardening-suggester validates a system configuration file in YAML against a security baseline written as a JSON Schema, using pyyaml to parse the configuration and jsonschema to run the validation. That single job is stated whole, with no extra duties added.

CHECK AGAINST THE BASELINE

REPORT ITEMS, BY PROPERTY PATH

Every validation failure becomes one report item at the failing property path, carrying the schema error message, and, where the baseline carries them at that path, a recommendation and a severity level. Where the baseline carries nothing for a path, the report shows a default note that no specific recommendation is available and a Medium severity.

Report Item, Fully Furnished

Property path: the failing property, named at its path.

Schema error message: carried from the validation.

Recommendation: the one the baseline carries at that path.

Severity: the level the baseline carries at that path.

Report Item, Default Note

Property path: the failing property, named at its path.

Schema error message: carried from the validation.

Recommendation: no specific recommendation is available.

Severity: Medium.
